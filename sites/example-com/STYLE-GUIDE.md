# STYLE-GUIDE · Example-Com
> 用途：给前端改造定方向的可迁移风格画像。只含原子与原则，不含布局/组件/结构。整段粘给编码 agent。

## 风格定调
主风格：Minimalism
气质词：calm / clean / clear
保持清晰而克制的层级，并让核心信息优先出现。使用稳定的留白建立节奏，避免把页面塞满装饰。

## 主题色（只保留 L1/L2 稳定色）
- 使用背景 #eeeeee、分隔面 未确定、正文 #000000、次要 #334488。
- 仅将强调 未确定 用于 CTA 与关键数据，保持克制。
- 用大面积中性打底，避免铺满强调色。

## 字体
- 使用字体栈：system-ui, sans-serif
- 维持高对比层级，标题 24/700，不要引入装饰字体。

## 间距 / 密度
- 以 8px 为基准，整体偏疏 airy；用留白而非分隔线建立节奏。

## 圆角 / 阴影
- 保持克制 restrained圆角（约 0px）。
- 使用无 none阴影：none。

## 该做 / 该避免
- 做：保持色彩克制、留白撑场、层级靠字重字号。
- 避免：多强调色并置、重阴影、信息紧凑堆叠。
