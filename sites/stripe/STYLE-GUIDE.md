# STYLE-GUIDE · Stripe

> 用途：给前端改造定方向的可迁移风格画像。只含原子与原则，不含布局/组件/结构。整段粘给编码 agent。

## 风格定调

主风格：Minimalism · 次风格：Editorial  
气质词：minimal / calm / premium / trustworthy

维持克制的现代极简：让留白、清晰字阶和深蓝正文建立可信感。以单一紫色强调关键动作，避免把装饰当作信息层级。

## 主题色（只保留 L1/L2 稳定色）

- 使用背景 `#ffffff`、分隔面 `#f6f9fc`、正文 `#0a2540`、次要 `#425466`。
- 只把强调色 `#635bff` 用在 CTA 与关键数据，占比保持在 5% 以下。
- 用大面积中性色打底；不要并置多个高饱和强调色。

## 字体

- 使用 `Inter, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`。
- 保持高对比层级：标题约 48px/700，正文 16px/400；不要引入装饰字体。

## 间距 / 密度

- 以 8px 为基准并保持偏疏节奏；优先用留白而非分隔线组织内容。

## 圆角 / 阴影

- 使用约 10px 的圆润圆角。
- 阴影保持轻量：`0 2px 8px rgba(10,37,64,.08)`；不要使用厚重漂浮阴影。

## 该做 / 该避免

- 做：克制点缀强调色，让字号和字重承担层级。
- 避免：密集信息堆叠、重阴影和大面积强调色。
