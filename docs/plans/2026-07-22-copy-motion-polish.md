# 文案与动效优化计划

## 目标

- 移除项目内的示例收藏，让列表只保留真实收藏记录。
- 将产品表达统一为：记录喜欢的网站风格，积累审美，并为未来项目提供可复用的设计方向。
- 让界面反馈自然、克制、连续，并在减少动态效果偏好下保持可用。
- 修正生成指南的措辞和风格建议，使其准确地基于已提取的视觉 token 与风格判断。

## 非目标

- 不新增收藏、分析或导出功能。
- 不复制被收藏网站的页面结构、组件或布局。
- 不新增第三方依赖。
- 不提交或推送 Git 变更。

## 假设

- README 中的 `example.com` 与 `example-com` 仅为命令占位符，不属于收藏数据；将分别改为 `<url>` 与 `<id>`，避免与已删除的示例混淆。
- 域名 slug 继续作为稳定标识；仅修正展示名称。

## 风险与处理

| 风险 | 处理方式 |
| --- | --- |
| 文案简化后失去专业准确性 | 保留 `token`、`STYLE-GUIDE.md`、CSS 等必要术语，并以真实功能为准。 |
| 通用指南模板与具体风格矛盾 | 仅从风格分类及已提取 token 生成建议；对冲突规则以具体风格为准。 |
| 切换期间旧异步结果覆盖新选择 | 用当前选择标识或等效取消机制守卫写入；连续交互以最后一次输入为准。 |
| 动效造成闪烁、双重曝光或操作阻塞 | 使用稳定 DOM、仅合成层属性、短时长和可中断状态，不锁定点击。 |
| 减少动态效果偏好被忽略 | 在 CSS 与交互路径中验证 reduced-motion 分支，不仅依赖视觉默认值。 |

## Review Findings

_待评审后追加；不得改写上述计划。_

- 审计发现：选择切换的异步工作缺少版本守卫，旧选择可能在新选择后回写；同时画廊与 Tab 的容器重建会扰动焦点和过渡。已以稳定 DOM 和 `selectionVersion` 守卫修复。
- 审计发现：生成模板含不受 token 支撑的通用禁令，可能与具体风格冲突；并有中英词语粘连。已改用纯中文 token 描述和中性、风格驱动的模板。
- 最终验证：typecheck 通过；测试 `8/8` 通过；快速切换 10 次、焦点保持、复制、console/pageerror 与 reduced-motion 检查均通过；动画评审结论为 Approve。
- 项目未提供 lint script，故无独立 lint 命令可运行；未提交或推送。
