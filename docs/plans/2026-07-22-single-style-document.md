# 单一风格文档与语义预览

## 目标

让收藏的风格以一份清晰、可直接交给设计或编码 AI 的 Markdown 文档交付；同时修正字体抽取误判，并让色彩区以真实用途而非抽象色块表达。

## 假设

- `STYLE-GUIDE.md` 是面向复用的唯一导出载体；不再在界面中暴露 `tokens.json`、Tailwind 或独立 CSS 导出。
- CSS 变量仍有价值，但应作为 `STYLE-GUIDE.md` 内的代码块，而不是单独的输出格式。
- 对 Codex Resets，主要字体应为 `"Baloo 2", "Arial Rounded MT Bold", system-ui, sans-serif`，而不是由非文字节点计数导致的 Arial。

## 委派与步骤

1. 由 **deep-reasoner** 定稿字体可视权重规则、六类色彩的语义样例及单文档章节结构。
   - 涉及文件：`skill/scripts/normalize.ts`、`index.html`、`skill/scripts/persist.ts`。
   - 验收：规则仅依据真实文字样本，文档结构可完整覆盖复用所需信息。

2. 由 **fast-worker** 建立并维护本计划文档，按以下顺序实施，完成一项勾选一项。
   - 涉及文件：`docs/plans/2026-07-22-single-style-document.md`。
   - 验收：计划保留原始内容，并在实施后附上实施说明与偏差记录。

3. 由 **fast-worker** 修正归一化阶段的字体选择：排除无真实文本的样本，按可视权重选择主字体，并保留合理回退；更新 Codex Resets 的已持久化结果为 Baloo 2 字体栈。
   - 涉及文件：`skill/scripts/normalize.ts`、相关测试、`sites/codex-resets-com/site.json`、可能生成的 `STYLE-GUIDE.md`。
   - 关键决策：文字样本以可见文本为前提，可视权重优先考虑文字区域和字号；没有有效文字时才使用现有通用回退。
   - 风险：不同抓取环境的文字尺寸可能不完整；回退必须稳定，不能生成空字体。
   - 验收：Codex Resets 主字体不再为 Arial，现有归一化测试与新增覆盖均通过。

4. 由 **fast-worker** 调整核心色彩区，使六种 token 通过实际界面语义表达：页面背景、承载表面、正文段落、辅助信息、强调操作、边界结构；将辅助文案改为“点击样例 · 复制色值”。
   - 涉及文件：`index.html`。
   - 关键决策：每个样例展示其真实用法，不以统一边框色块替代；正文与次要文字必须在视觉层级上可区分。
   - 风险：样例内的文字对比度不足或窄屏堆叠造成拥挤。
   - 验收：六类色彩均可辨识其用途，点击样例能复制对应色值，桌面与移动端均无横向溢出。

5. 由 **fast-worker** 将导出区收敛为唯一的 `STYLE-GUIDE.md`：区块标题为“风格文档”，短句为“完整记录 · 直接交给 AI”，说明为“汇总风格方向、视觉参数与 CSS，可直接作为设计或编码提示词。”，按钮为“复制风格文档”。
   - 涉及文件：`index.html`、`skill/scripts/persist.ts`、相关测试与生成的风格文档。
   - 关键决策：Markdown 必须包含用途、风格方向、语义色、字体与字阶、间距与形态、CSS、使用边界；CSS 置于文档中供直接复用。
   - 风险：删除多格式选项后遗留的选择状态、事件处理或模板节点会导致复制失败。
   - 验收：页面只保留一个文档预览与一个复制入口；复制内容与生成的 `STYLE-GUIDE.md` 一致，且包含所有约定章节。

6. 由 **fast-worker** 清理多格式 tabs、JSON/Tailwind/CSS 独立输出及其浏览器模板孤儿逻辑，仅删除本轮收敛所产生的无用代码。
   - 涉及文件：`index.html` 及与导出格式直接相关的测试。
   - 验收：不存在不可达的格式选择、旧标签、旧帮助文案或无引用的导出处理函数。

7. 由 **qa-runner** 执行类型检查、测试与浏览器 QA。
   - 涉及文件：测试输出与本计划的实施说明。
   - 验收：归一化及持久化测试通过；桌面与移动端截图确认字体、色彩语义、单文档复制与无横向滚动；失败项如有须明确记录并回流给 fast-worker 修复。

## 实施说明

已按计划实施：字体归一化仅对真实、非媒体文字样本累积 `clamp(width, viewport) × fontSize` 的可视权重，并以原始采集顺序稳定打破平局；无有效文字时回退到 body/root 字体，最后才使用系统字体。Codex Resets 使用既有 raw 数据重新归一化与 finalize，主字体更新为 Baloo 2 字体栈。

`STYLE-GUIDE.md` 现在是唯一的导出载体，补充了用途、迁移边界、语义色用途表、字阶、间距与形态、语义 CSS 及使用边界；查看器只加载并复制这一磁盘文件。移除了多格式输出、浏览器端指南生成与格式选择逻辑。色彩区改为背景画布、表面、正文、辅助信息、强调操作和边框内容框六种语义样例，并为可复制样例添加明确的 aria-label。

收尾修正：已精确删除旧多格式导出专用的 `.tabs`、`.tab`、选中和按压状态规则；未格式化或改动其余压缩样式。

## 评审记录

QA 发现浏览器默认请求 `/favicon.ico` 返回 404。根因是页面未声明 favicon，仓库中也没有可复用图标资源。已新增与当前奶油底色、黑色字形和橙红强调色一致的最小 `favicon.svg`，并在页面 head 中显式声明；浏览器不再请求不存在的默认 `/favicon.ico`。
