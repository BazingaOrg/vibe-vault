# Vibe Vault

When a user asks to extract, collect, save, or analyze a website's transferable visual/design style, activate the project Style Extractor workflow. Read and follow [skill/SKILL.md](skill/SKILL.md) before taking action.

This workflow extracts atomic visual tokens, structured visual grammar, and a style direction; it does not reproduce layouts, components, or page structure.

When reporting a finished extraction, separate **design tokens/visual grammar** from **components/layout** and from **charts/media/data ink**. Use multi-view evidence under `.style-extractor/<id>/evidence/` for judgment; promote a cleaner cover screenshot when the primary frame is chart-heavy (see skill).
